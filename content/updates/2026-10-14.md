上一次更新完成了「生活」和「关于」两个页面的整合，但主页还停留在之前的结构：八张卡片里，动漫追番、画廊更新仍按旧分类展示，入口也指向已经并入「生活」的旧页面；「关于这个网页」「关于我」又和关于页、生活页的内容重复。主页逐渐变成了各个页面的缩略合集，而不是一个真正的入口。

这次更新把主页重新定位为**网站入口、最近动态与内容预览**：不再承担大段的个人介绍，而是让人一眼看到网站最近在更新什么，并且能从这里直接进入具体的内容。

下面同样按照「更新前 → 更新后 → 具体改动」的顺序介绍。

## 一、桌面端：更新前

![更新前的桌面端主页：三行共八张卡片，动漫追番、画廊更新、关于我等卡片沿用旧的页面分类](/assets/updates/home-2026-10-14-desktop-before.webp)

更新前的主页由三行、八张卡片组成：

- 第一行：关于这个网页、今日心情、站点统计。
- 第二行：笔记更新、动漫追番、画廊更新。
- 第三行：更新公告、关于我。

随着网站结构的调整，这套布局积累了不少问题：

- **分类过时**：动漫和画廊已经并入「生活」，主页却仍然把它们作为两张独立的卡片，点击后还会先跳到旧地址再被转到生活页。
- **内容重复**：「关于这个网页」与关于页概览重复，「关于我」与生活页顶部的个人介绍重复。
- **入口不够直接**：点击某一篇笔记，只能进入笔记列表，还需要再找一次才能打开文章。
- **名不副实**：「今日心情」实际展示的是东京的实时天气和根据天气生成的一句话，并不是手动记录的心情。
- **统计意义不大**：站点统计用进度条把笔记、追番、画廊三项互相比较，比例本身没有实际含义，「追番」「画廊」也是旧的分类名称。
- **行高固定**：卡片所在的行高度是写死的，内容少的卡片留下大片空白，内容多的卡片又显得拥挤。

## 二、桌面端：更新后

![更新后的桌面端主页：顶部轻量欢迎区，第一层为今日一隅、最近更新、站点速览，第二层为数学与笔记、生活片段](/assets/updates/home-2026-10-14-desktop-after.webp)

新的主页由三部分组成：

- **轻量欢迎区**：页面顶部一条高度约 140px 的横幅，左侧是标题，右侧是 Q 版人物。
- **第一层：三张信息卡**：今日一隅、最近更新、站点速览，三列等宽，内容轻量。
- **第二层：两张内容卡**：数学与笔记（较宽）、生活片段，这是主页最重要的内容展示区域。

所有卡片的高度都改为由内容决定，同一行的卡片自动等高，并且通过调整卡片内部的排布，让多出来的高度不再变成空白。

## 三、桌面端更新内容

### 1. 轻量欢迎区

欢迎区只保留三行文字：小字「HOME · YANG181969」、主标题「欢迎来到我的小站 ✨」和一句副标题「数学、生活与那些值得留下的瞬间」。右侧沿用原来「关于这个网页」卡片里的 Q 版人物，并且延续每天自动更换一张的轮换规则。

背景使用与生活页、关于页一致的主题色渐变和柔和光晕，没有加入大幅背景图片或额外按钮，切换主题色和深色模式时会一起变化。

### 2. 今日一隅

原来的「今日心情」更名为「今日一隅」，内容仍然是东京的实时天气：天气图标、温度、天气描述，以及根据天气挑选的一句话和对应表情的 Q 版人物。

在此基础上做了几处调整：

- 新增一行东京当天的日期和星期。
- 人物从卡片右下角的绝对定位改为与文字并排，内容在卡片中垂直居中，不再出现上半部分有字、下半部分空白的情况。
- 天气接口超过 8 秒没有响应时视为失败，显示「东京天气暂时没有回应」和默认的人物与句子，之后每小时自动重试。天气失败不会影响其他卡片的加载。

### 3. 最近更新

「更新公告」更名为「最近更新」，展示最新的三条更新日志：

- 每条左侧是醒目的日期块（月.日 + 年份），右侧是标题和一行摘要。
- 点击任意一条，直接打开关于页中对应的更新详情。
- 卡片底部显示日志总数，并提供「完整更新日志 →」入口。

### 4. 站点速览

原来的「站点统计」简化为「站点速览」，只展示四个真实数字和建站天数，去掉了没有实际意义的比例进度条：

- **笔记**：笔记篇数。
- **作品**：生活页中的动漫作品数（原来的「追番」）。
- **收藏**：生活页中的画廊图片数（原来的「画廊」）。
- **更新**：更新日志总条数。

这些数字与关于页概览、统计分区使用同一份数据和同一种计算方式，建站天数在三个地方始终一致。点击卡片的任意位置即可进入关于页的统计分区。

### 5. 数学与笔记

这是主页上最重要的一张卡片，宽度约占整行的 7/12：

- 展示最新的三篇笔记，每篇包含标题、分类、日期，以及正文第一段的简短预览。
- 预览中的行内公式会用 KaTeX 正常渲染，较长的段落会在两行后省略，并且不会在公式中间截断。
- **点击某一篇笔记会直接打开这篇文章**，不再只是进入笔记列表；点击卡片标题则进入笔记页。
- 预览加载完成之前会预留好位置，文字出现时下方的卡片不会被推动。

### 6. 生活片段

动漫追番、画廊更新、关于我三张卡片合并为一张「生活片段」，展示生活页中已有的内容：

- 四张缩略图：两部最近更新的作品，两张精选收藏图片。缩略图左上角标注「作品」或「收藏」，作品下方显示名称。
- 点击作品打开对应的作品详情，点击收藏进入生活页的收藏画廊。
- 下方是「作品、收藏、足迹、日记」四个分区入口，直接进入生活页对应的分区。
- 日记中有内容时，还会显示最新一篇日记的入口。

缩略图会自动填满卡片的高度，与旁边的笔记卡片保持等高；卡片较窄时改为两行两列。收藏图片会优先挑选竖向的图片，并让裁切位置略微偏上，尽量避免人物的脸被裁掉。

## 四、移动端：更新前与更新后

![移动端首屏对比：左图为更新前，首屏只有关于这个网页和今日心情两张卡片；右图为更新后，首屏可以直接看到欢迎区、最新笔记和生活片段](/assets/updates/home-2026-10-14-mobile-compare.webp)

更新前，移动端只是把桌面端的八张卡片按原顺序纵向排列：首屏几乎被「关于这个网页」和「今日心情」占满，天气卡下半部分是一大块空白；最新的笔记要往下滑过统计卡才能看到，画廊更新的四张大图又让页面变得很长。

更新后，移动端按照内容的重要程度重新排列：

1. 轻量欢迎区
2. 数学与笔记
3. 生活片段
4. 最近更新
5. 今日一隅
6. 站点速览

![移动端整页长度对比：同一比例缩放，更新前约 2220px，更新后约 1642px](/assets/updates/home-2026-10-14-mobile-length.webp)

同时针对小屏幕重新调整了各张卡片：

- 所有卡片使用自然高度，清除了桌面端固定行高留下的影响，页面总长度从约 2220px 缩短到约 1642px，减少了大约四分之一。
- 首屏就能看到最新的笔记；至少两篇笔记无需滑动即可看到。
- 生活片段的四张缩略图排成一行，保持 3:4 的比例，图片加载前就占好位置，不会出现跳动。
- 站点速览的四个数字排成一行；今日一隅的人物与天气信息并排，卡片高度明显降低。
- 欢迎区在手机上压缩到约 110px，标题过长时自然换行，不会被裁切。
- 平板宽度下使用两列布局：笔记与生活并排，最近更新独占一行，今日一隅与站点速览并排。
- 在 320px 宽的小屏幕上也不会出现横向滚动，最后一张卡片不会被底部导航栏遮挡。

## 五、跳转与交互

主页上的所有站内链接现在都统一交给网站自己的页面切换逻辑处理，不再整页刷新：

| 点击位置 | 打开的内容 |
| --- | --- |
| 某一篇笔记 | 笔记页中的这篇文章 |
| 「数学与笔记」标题 | 笔记页 |
| 某一条更新 | 关于页 · 更新分区中的这条日志 |
| 「完整更新日志 →」 | 关于页 · 更新分区 |
| 站点速览卡片 | 关于页 · 统计分区 |
| 作品缩略图 | 对应的作品详情 |
| 收藏缩略图 | 生活页 · 收藏画廊 |
| 作品 / 收藏 / 足迹 / 日记 | 生活页对应分区 |

- 浏览器的前进、后退和刷新都能回到正确的位置，复制带有文章或日志的地址直接打开也可以正常显示。
- 按住 Ctrl（Mac 上为 Command）点击，仍然会在新标签页中打开。
- 在主页数据还没加载完时就切换到其他页面，迟到的数据不会再改动新页面的内容；返回主页时卡片会重新正常加载。
- 主页不再生成指向旧动漫、画廊页面的链接，旧地址本身仍然可以访问并自动跳转到生活页。
- 所有条目都可以用键盘 Tab 选中，按 Enter 打开。

## 六、性能与稳定性

- **更新卡片不再下载全部日志正文**：原来为了显示三条标题，主页会把所有更新日志的 Markdown 文件全部下载一遍；现在只读取一份更新索引，并且与关于页共用同一次请求。
- **数据共用**：站点数据、笔记索引在主页与关于页之间共用，同一次访问中不会重复请求。
- **笔记预览按需加载**：只请求主页上展示的三篇笔记，同一次访问中只加载一次。
- **失败互不影响**：天气、更新、统计、笔记任意一项加载失败，都只在对应的卡片中显示提示，其他卡片照常显示。
- **清理旧缓存**：清除了旧版主页卡片留在浏览器中的过期缓存，笔记列表不会再因为缓存而延迟一天才显示新文章。

## 七、总结

这次主页重构没有改变网站的整体视觉风格，浅蓝与白色的玻璃质感、圆角卡片、Q 版人物和主题色系统都保持不变，主要调整的是结构和功能：主页从「每个页面放一张卡片」变成了「最近动态 + 内容预览」，卡片数量从八张减少到五张，但从主页直接到达具体内容的路径更短了。

至此，主页、笔记、生活、关于四个一级页面的结构调整全部完成，接下来会进入细节打磨阶段。
