
# 全站悬浮导航：桌面侧栏与移动端顶栏、底栏改为独立悬浮的纸片

上一次更新为网站换上了「坐标纸 + 雾面纸张」的材质，结尾提到接下来要打磨导航的形态。导航之前都是贴着屏幕边缘的长条：桌面端的侧栏占满左侧整个高度，移动端的工具栏和底部导航横向铺满屏幕。卡片已经是一张张放在坐标纸上的纸片了，导航却还像是网页的「边框」，两者的风格并不统一。

这次更新把三处导航都改成了**独立悬浮的纸片**：它们和卡片使用同一套纸张材质，跟随外观设置里的纸张样式、深浅主题和主题色变化，只是背景的不透明度保持在较高的水平，保证文字和图标始终清晰。页面的路由、导航入口和各个工具的功能都没有变化。

下面按照「桌面端 → 移动端 → 平板 → 细节」的顺序介绍。

## 一、桌面端：更新前

![更新前的桌面端主页：侧栏是一条贴着屏幕左边缘、占满整个高度的长条](/assets/updates/float-2026-10-16-desktop-before.webp)

更新前，侧栏紧贴屏幕左侧和上下边缘，右侧用一条竖线和正文分开。它更像是页面的边框，和右边一张张带圆角、带阴影的卡片不在同一个层次上。

## 二、桌面端：更新后

![更新后的桌面端主页：侧栏变成一张四周留白、带圆角的悬浮纸片，和右侧的卡片处在同一层次](/assets/updates/float-2026-10-16-desktop-after.webp)

更新后，侧栏是一张完整的悬浮纸片：

- **四周留白**：距离屏幕左边、上边、下边各 16px，和正文之间也隔着 16px，外圆角 22px，配合细描边和轻阴影。
- **一张纸，不拆分**：头像与名字、展开按钮、四个页面、音乐 / 计时 / 日历、搜索 / 主题都放在同一张纸片里，顺序和之前完全一样。
- **正文更宽**：正文区域自身的左右边距从 40px 调整为 24px，侧栏收起时第一张卡片离屏幕左边 124px，展开时为 248px。

## 三、侧栏的收起与展开

![侧栏的两种状态：左图为收起（68px），右图为展开（192px），展开时正文被整体推向右侧，而不是被侧栏盖住](/assets/updates/float-2026-10-16-sidebar.webp)

- **两种宽度不变**：收起 68px，展开 192px，图标在两种状态下都保持在同一条竖线上，展开时不会左右跳动。
- **只用按钮切换**：鼠标经过侧栏时不会自动展开，只有点击展开按钮才会切换；选择会被记住，刷新页面、切换页面后都保持不变。窗口变窄时，只要仍然是桌面布局，也不会擅自收起。
- **推开正文，不盖住正文**：展开和收起大约用时 0.22 秒，正文会跟着平滑地让出或收回空间，过程中侧栏与正文之间始终保持 16px 的间距。
- **很矮的窗口也能用**：例如把浏览器窗口拖得很矮时，侧栏中间的「页面 + 小组件」区域可以单独上下滚动，底部会出现一层淡淡的渐隐，提示下面还有内容；头像和展开按钮固定在上方，搜索和主题固定在下方，任何按钮都不会被挤到看不见的地方。
- **外观设置的位置**：从侧栏打开外观设置时，面板会出现在侧栏纸片右侧 10px 处，并向上展开，不再紧贴侧栏边缘。

## 四、移动端：顶部工具栏与底部导航

![移动端对比：左图为更新前，顶部工具栏和底部导航都横向铺满屏幕；中图为更新后，顶部工具栏左右内缩、底部导航变成完整悬浮的纸片；右图为更新后在「生活」页向下滚动时的样子，分区标签栏停在顶部，返回按钮位于底部导航上方](/assets/updates/float-2026-10-16-mobile-compare.webp)

**顶部工具栏**改为「半悬浮」的纸片：

- 顶边与屏幕顶部（刘海屏则是系统状态栏下方）相接，左右两侧向内收，底部两个角为 18px 圆角。
- 左右内缩的距离和下方卡片的页面边距相同，所以卡片的左右边缘正好和工具栏对齐。
- 工具栏本体高 56px。屏幕宽度不超过 480px 时只显示头像，更宽时显示「Yang181969」；音乐、计时、日历、搜索、主题五个按钮的点击区域都是 44×44px，即使把系统字体调大，被压缩的也只会是名字，按钮不会变小。

**底部导航**改为完整悬浮的纸片：

- 四个角都完整可见，高 62px，圆角 20px，距离屏幕底部 8px（带有底部横条的手机会额外避开系统的安全区域）。
- 手机上左右各留出至少 12px；在平板上最宽 480px，并在屏幕中间居中。
- 仍然是主页、笔记、生活、关于四个入口，图标在上、文字在下，当前页面使用淡色高亮。之前在 480px 以下的窄屏上，图标和文字会缩小到 20px / 10px，现在所有宽度统一为 22px / 11px。
- 页面滚动到底时，页脚和最后一张卡片会完整地停在导航上方，不会被挡住。

## 五、滚动与面板

![移动端向下浏览「关于 · 更新」后再稍微往回滑：左图为更新前，右图为更新后。两种情况下顶部工具栏都会重新出现，分区标签栏停在它的下方](/assets/updates/float-2026-10-16-mobile-scroll.webp)

- **滚动规则没有变**：向下滑动一小段，顶部工具栏会收起，给内容让出空间；向上滑一点或回到顶部、切换页面时，它会重新出现。工具栏隐藏和出现时只是移动它自己，下面的内容不会跟着跳动。
- **分区标签栏**：「生活」和「关于」页面的分区标签栏在滚动时停在工具栏下方 8px；工具栏收起后，标签栏也会跟着上移，两者不会重叠。
- **打开工具面板时**：无论是点击按钮，还是在电脑上按 Ctrl / Cmd + K 打开搜索，顶部工具栏都会先显示出来，并且在面板打开期间不再自动收起；关闭面板后，焦点回到对应的按钮上。
- **软键盘**：在页面里的输入框中打字、软键盘弹出并占据屏幕时，底部导航会暂时滑出屏幕，把空间留给输入框，键盘收起后自动回来。只是点一下输入框、或者使用外接键盘时，导航不会消失。

## 六、平板：返回按钮

![平板（768px 宽）对比：左图为更新前，底部导航横向铺满，返回按钮位于导航上方；右图为更新后，底部导航以 480px 宽居中，两个返回按钮移到导航右侧的空白处，并贴近屏幕右下角](/assets/updates/float-2026-10-16-tablet-compare.webp)

「返回上一页」和「返回顶部」两个按钮现在**以屏幕右下角为准**定位，不再跟随居中的底部导航：

| 屏幕宽度 | 按钮组位置 |
| --- | --- |
| 手机（约 640px 以下） | 距离屏幕右边 16px，位于底部导航上方 12px |
| 约 640px–770px | 导航右侧的空白放得下按钮后，随屏幕变宽逐渐下降到导航旁边，右边距也从 16px 逐渐变为 24px |
| 约 770px–900px | 距离屏幕右边 24px，位于底部导航右侧，最下面的按钮与导航对齐 |
| 桌面 | 与之前相同，距离屏幕右边和底边各 24px |

按钮的位置是根据「导航右侧实际剩下多少空白」连续计算出来的，而不是到某个宽度突然切换：只有空白足够放下按钮、并且与导航至少隔开 12px 时，按钮才会开始往下移，屏幕每变宽 1px，按钮最多移动半个像素，拖动窗口时不会突然跳位。如果设备右侧有系统安全区域（例如横屏时的刘海），这部分宽度也会被扣除，空间不够时按钮会留在导航上方，因此在任何宽度下按钮都不会压到导航上。按钮的外观、出现的时机和功能都没有变化，打开音乐、日历等工具面板时，面板仍然会盖在按钮和导航之上。

## 七、统一的页面边距

之前移动端页面的左右边距分散在几个地方分别设置，有的宽度上卡片和工具栏的边缘对不齐。这次统一为一套规则：

| 屏幕宽度 | 更新前 | 更新后 |
| --- | --- | --- |
| 480px 及以下 | 8px | 8px |
| 481px–639px | 8px | 12px |
| 640px–900px | 18px | 16px |
| 桌面（正文区域内） | 40px | 24px |

移动端的这组边距同时决定了顶部工具栏的左右内缩，卡片与工具栏因此总是对齐的。底部导航所占的空间也只在一个地方计算，页面、搜索面板和返回按钮都从同一处读取，不会重复叠加出多余的空白。

## 八、细节与兼容

- **首屏不跳动**：首屏使用的关键样式和完整样式同步更新，页面刚打开时导航就已经是悬浮的形态，不会先出现贴边的长条再跳成纸片。
- **跟随外观设置**：三种纸张样式（轻薄、描边、层叠）、深浅主题和主题色都会同步应用到侧栏、工具栏和底部导航上；导航依旧不使用背景虚化，文字和图标不会随纸张变得透明。
- **减少动态效果**：如果系统开启了「减少动态效果」，侧栏展开、工具栏显隐、底部导航让位等过渡都会直接切换，不播放动画。
- **其余不变**：笔记详情页、旧链接的跳转、浏览器的前进后退、音乐播放与进度环、计时器、日历和搜索都与之前保持一致。

调整完成后，在 320px 到 1920px 之间的十多种屏幕宽度下，以及 901×400 这样很矮的窗口里，逐一检查了导航的位置、按钮能否点到、页面有没有出现横向滚动条。目前的检查都在电脑浏览器的模拟环境中完成，真实手机上的刘海、底部横条和软键盘表现还会在实际使用中继续观察。

## 九、总结

这次更新没有改动页面的内容和结构，主要是让导航也成为「放在坐标纸上的纸片」：桌面端是一张悬浮的侧栏，移动端是一张半悬浮的顶栏和一张完整悬浮的底栏，它们和卡片使用同一套材质与边距规则。整个网站因此少了「边框」的感觉，更像一本摊开的数学手账。
