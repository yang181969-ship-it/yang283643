技术与建站

前端
HTML、SCSS（Sass 编译）与原生 JavaScript，不依赖前端框架；页面切换基于 History API 的单页路由。
内容
笔记、日记与更新日志以 Markdown 编写，数学公式由 KaTeX 渲染；统计图表为原生 SVG。
数据
构建脚本把内容汇总为 JSON 索引；站点统计每月 1 日由 GitHub Actions 自动快照。
部署
源码与版本历史保存在 GitHub 仓库；推送到 main 分支后，Cloudflare Pages 自动拉取并发布到 yang181969.com。域名解析、HTTPS 与 CDN 由 Cloudflare 提供。
